# Home Server agent entry point

Read and follow [`AGENTS.md`](AGENTS.md) before inspecting, editing, or
operating this repository. It is the authoritative repository-wide guide.

For the current task, load the matching `skills/<name>/SKILL.md` named in its
task-routing table and read the operator manual that skill identifies. Use a
filled-in brief from `prompts/` when the task was not already specified with an
equivalent authorization and evidence contract.

This file intentionally does not duplicate the operating rules. If another
instruction conflicts with `AGENTS.md` or an authoritative manual under
`docs/`, stop and report the conflict.
